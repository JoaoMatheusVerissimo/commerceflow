# Applications

Aplicações voltadas à experiência do usuário ficam neste diretório.

`frontend` contém a aplicação React + TypeScript da Fase 1, com cadastro, login e página de conta. Concretiza o frontend previsto no monorepo; não há segunda aplicação `web`. Consulte o [guia Foundation](../docs/foundation.md). Painel administrativo, CRM e analytics pertencem a fases futuras.
