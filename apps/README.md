# Applications

Aplicações voltadas à experiência do usuário ficam neste diretório.

O primeiro componente previsto é `web`, uma aplicação React + TypeScript que atenderá inicialmente a loja e, nas fases posteriores, o painel administrativo, CRM, Customer 360 e analytics. O diretório executável será criado apenas na fase em que sua fundação for implementada, para não representar código inexistente.
